# Task Manager / Todo App

## About The Project

Task Manager is a responsive and interactive Todo Application built using HTML, CSS, and JavaScript. The application helps users create, manage, search, and organize daily tasks efficiently.

The project focuses on improving productivity through a clean user interface and smooth task management experience. Users can add tasks, search existing tasks, delete completed tasks, and store task data permanently using Local Storage.

This project was created to strengthen frontend development skills including DOM manipulation, event handling, responsive design, and browser storage management.

---

## Features

* Add new tasks
* Delete tasks
* Search tasks instantly
* Store tasks in Local Storage
* Responsive design for mobile and desktop
* Smooth UI interactions and hover effects
* Scrollable task container
* Task creation form with validation
